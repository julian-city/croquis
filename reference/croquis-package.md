# croquis: Transit Sketch Planning with GTFS

Tools for rapidly creating detailed and realistic transit networks and
schedules in GTFS format, including a front-end Shiny app called
Croquis. Introduces the Simplified Speed and Frequency Specification
(ssfs), a data structure that simplifies GTFS creation and editing.
Includes functions for conversion between SSFS and GTFS formats.
Includes a calibration engine which adjusts SSFS speeds based on a
reference GTFS. Output GTFS are compatible with travel demand and
accessibility analysis tools such as r5r.
