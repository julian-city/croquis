# STM Ligne Jaune sample network

A sample SSFS (Simplified Frequencies and Speeds Specification) object
representing the STM Ligne Jaune (Yellow Line) metro service in
Montreal. This is the simplest sample network and is useful for getting
started with Croquis.

## Usage

``` r
ligne_jaune
```

## Format

An ssfs object (a named list of 8 tables).

## Source

Created by the package author based on public GTFS data.
